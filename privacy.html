DealBot（優惠顧問）隱私權政策

最後更新：2026-11-07

這是誰的應用程式

DealBot 是個人使用的工具，只供擁有者本人使用，不對外提供服務。

存取哪些 Google 資料

  • 只使用 Google Calendar 的 calendar.app.created 權限：建立一本名為「優惠登錄」的日曆，並在這本日曆裡新增、修改、刪除優惠登錄提醒。
  • 不讀取、不修改使用者其他日曆或行程，也不存取 Gmail、雲端硬碟、聯絡人等任何其他 Google 資料。

資料存放與分享

  • 授權憑證與日曆行程的對照紀錄，只存放在擁有者自己的家用伺服器上（檔案權限僅擁有者可讀）。
  • 不出售、不分享、不轉交任何 Google 使用者資料給第三方，也不用於廣告。
  • Google 使用者資料的使用遵守 Google API Services User Data Policy，包括 Limited Use 規範。

如何撤銷

隨時可以到 Google 帳戶的「第三方存取權」 移除 DealBot 的存取權； 刪除「優惠登錄」日曆即可清除它建立的所有行程。

English summary

DealBot is a single-user personal tool. It only uses the calendar.app.created scope to create one secondary calendar ("優惠登錄") and manage reminder events in it. It does not read or modify any other calendar or Google data. Credentials and event mappings are stored only on the owner's home server and are never sold or shared with third parties. Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
